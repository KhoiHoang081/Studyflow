STUDYFLOW - QUẢN LÝ HỌC TẬP

1. Cài Node.js 20 trở lên.
2. Mở terminal trong thư mục này, chạy: npm start
3. Mở http://localhost:4173
4. Hướng dẫn đầy đủ: README.md
5. Đưa lên GitHub: xem mục "Đưa lên GitHub và chạy website" trong README.md.
6. Dữ liệu lưu trên trình duyệt. Xuất bản sao lưu JSON định kỳ.

Không cần npm install. Không mở index.html trực tiếp bằng file://.
